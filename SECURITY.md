# Security Policy

Just For Phishing is a defensive security-awareness project. Please report vulnerabilities or abuse concerns responsibly.

## Supported version

The live site at <https://justforphishing.com/> and the default branch of this repository are the supported versions.

## Reporting a vulnerability

Please open a private security advisory in GitHub if available, or contact the repository owner directly through GitHub. Do **not** include working exploit code, real credentials, or sensitive learner data in a public issue.

When reporting, include:

- Affected page/module
- Steps to reproduce
- Browser/device information
- Potential impact
- Suggested fix, if known

## Scope

In scope:

- Cross-site scripting or unsafe DOM injection
- Privacy leaks beyond the disclosed analytics/CDN processing
- Broken access assumptions, unsafe external resources, or malicious dependency risks
- Accessibility issues that prevent safe completion of training modules

Out of scope:

- Denial-of-service against GitHub Pages, Cloudflare, or third-party providers
- Social engineering the maintainer or users
- Automated high-volume scanning
- Reports about intentionally educational phishing examples, unless they create real-world abuse risk

## Safe harbor

Good-faith, non-destructive research that respects this policy is welcome.
